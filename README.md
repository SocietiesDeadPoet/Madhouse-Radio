# Madhouse Radio

Madhouse Radio is a Twitch channel-panel project for DamadHattah.

It provides a themed gateway to DamadHattah's public Suno profile, where viewers can explore songs and playlists.

Suno profile: https://suno.com/@damadhattah603

## Pages

- `index.html` — Madhouse Radio landing page
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service

## Privacy

The current static version does not request Twitch viewer identity or operate its own user tracking, accounts, cookies, or backend.
